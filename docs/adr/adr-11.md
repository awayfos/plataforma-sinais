# ADR-11: Next.js 16, React 19, TypeScript, Tailwind e Lightweight Charts 5

- **Status:** aceita (design aprovado em 2026-11-25)
- **Fonte:** design §7.2

## Decisão

**Next.js 16 (App Router) + React 19 + TypeScript + Tailwind CSS** e **TradingView Lightweight Charts 5.x**.

## Motivo

Pedido no requisito, versões atuais e suportadas. O Lightweight Charts 5 tem plugins (primitivas) para desenhos e zonas.
