# ADR-15: Docker + Docker Compose em desenvolvimento e na primeira produção (um

- **Status:** aceita (design aprovado em 2026-11-25)
- **Fonte:** design §7.2

## Decisão

**Docker + Docker Compose** em desenvolvimento e na primeira produção (um servidor dedicado ou VPS em região permitida pela Binance).

## Motivo

Requisito. Suficiente para a V1.

## Alternativas descartadas

Kubernetes (prematuro).
