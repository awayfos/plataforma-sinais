# ADR-02: Python 3

- **Status:** aceita (design aprovado em 2026-11-25)
- **Fonte:** design §7.2

## Decisão

**Python 3.13**, gerenciado com `uv`.

## Motivo

Maturidade do ecossistema científico. Suporte do FastAPI, pandas, LightGBM. Versão exata validada na Fase 2.

## Alternativas descartadas

3.14 (adotar quando todas as dependências científicas suportarem).
